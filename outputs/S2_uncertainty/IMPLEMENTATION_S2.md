# S2 implementation, recorded before replicate estimates

S2-0 is complete. Calcium control-mean q=0.00933036263990268; linear-extrapolation q=0.06587592467028. Only the control-mean calcium impact belongs in the main text. The alternate reference is supplementary and reference-dependent. Both shifts in S1 came from calcium's own DiD, never from energy.

## Design and resampling

- Frozen pooled design: cycle-specific strata and PSUs, 74 strata, 151 PSUs, design df=77. Seventy-one strata have two PSUs and three have three PSUs. A 32-row balanced replicate design cannot balance all 74 strata; the three-PSU strata also preclude ordinary two-PSU Fay BRR without changing the design. Use the explicitly authorized fallback, not a reduced or coarsened design.
- Generate exactly 200 Rao–Wu rescaled stratified PSU bootstrap replicates with survey::subbootweights, fixed seed 2026102902. In stratum h, sample n_h-1 PSUs with replacement and multiply PSU counts by n_h/(n_h-1). Every person within a PSU receives the same multiplier. Generate weights on the full positive-WTDR2D pooled design, then apply the frozen analysis domains. Survey package scale=1/(200-1), mse=TRUE; no post hoc replicate replacement, dropping, or re-seeding.
- For each replicate, recompute the same weighted DiD coefficient with fixed v1.0 covariates, separately under both reference definitions, and all first-day energy means. WLS is algebraically the same point estimator as svyglm for the Gaussian identity model; SE is derived from the joint replicates, not an inner Taylor fit. Exact empty/aliased dummy columns may be represented by a full-rank basis without collapsing categories or changing the fitted model space.
- Correct each person's first day with expm1(log1p(intake)+replicate DiD); second-day raw intake is unchanged. Original and corrected estimates within a replicate use the same selected PSUs and weights. Retain the S1 joint iron/calcium NCI model, including re-estimating the iron DiD as an internal nuisance input to that same model; do not produce a new iron adequacy endpoint or change its NO_VALID_RESULT interpretation.
- Negative corrected daily amounts are outside the S1 NCI input domain. If encountered, record the affected replicate and input failure explicitly. Do not clip values, delete recall records, change population, discard that replicate, or manufacture a complete-chain CI from an incomplete replicate set.

## NCI and uncertainty

- Whole-sample point estimates retain the S1 full settings: four chains, 12,000 iterations, burn-in 2,000, thin 25; the full-sample audit in S2 will reproduce S1 before combining with replicate SEs.
- Replicate computation starts with four chains, 3,000 iterations, burn-in 1,000, thin 5. Require maximum univariate Gelman–Rubin Rhat <1.05 for every fitted replicate/scenario. If not satisfied, use S1 full length for that same replicate/scenario. This is numerical convergence repair, not a changed scientific gate; preserve the short-chain diagnostics. Do not shorten the full-sample analysis.
- Refit Box–Cox parameters, package preprocessing and the complete NCI model for each replicate/scenario. Keep S1 fixed covariate model space, weekend integration 25/10/10/4, first-recall reference, calcium EAR 800/1,000 mg/day, and foods/beverages-only scope. Use S1 seeds 102901–102904 and the same distribution seed 20261029 and 2,000 simulated random effects per person, to reduce algorithmic Monte Carlo differences. All N are people, never simulated rows.
- Report full-sample point estimate plus/minus the appropriate survey-df t critical value times the bootstrap SE: df=15 for original L-only energy means and calcium prevalence; df=77 for corrected estimates and changes that also depend on the pooled cross-cycle DiD. Variance uses all 200 deviations from the full-sample estimate with survey's scale and rscales. Paired differences use paired replicate differences, carrying covariance between original and corrected estimates and between DiD and intake distributions. Unbounded design-based Wald intervals are reported as computed, without arbitrary truncation.
- For calcium report corrected-minus-original differences (negative means reduction), CI inclusion of zero, CI inclusion of -2 percentage points, and the equivalent reduction-scale CI inclusion of +2 percentage points. The 2-percentage-point comparison does not apply to energy's kcal or log units. No v1.0 gate is reconsidered.
- Wall-clock budget 36 hours from S2 start. Do not reduce the 200 replicates. If any endpoint lacks a complete valid 200-replicate chain, its CI is NOT_RUN/NO_VALID_RESULT with the exact reason; this is not evidence of a null effect.

## Distribution aggregation optimization

Before the full replicate run, the NCI daily-calcium marginal was evaluated with the package's unchanged initialization, bivariate random-effect generator, and backtransformation. Only nuisance-level aggregation was vectorized with rowsum(), retaining aggregate simulation results rather than millions of simulated rows. Against all three saved S1 models and all 2,000 draws per scenario, the maximum per-draw prevalence difference was 4.98e-14 percentage points and the maximum per-draw mean difference was 5.69e-13 mg. This is numerical aggregation equivalence, not a substitute usual-intake method. Full-sample pooled prevalence differs only by floating summation order (below 1e-9 percentage points). See provenance/streaming_validation.csv.

## Degrees-of-freedom QA correction before CI calculation

The initial implementation note used pooled df=77 for every estimate. Independent source/design QA identified that original L-only estimates use 30 PSUs and 15 strata, so their df is 15. The corrected quantities depend on pooled-cycle DiD and retain pooled df=77. This technical correction was made before the CI summary was calculated; it changes no estimand, gate, population, cutoff, or resampling draw. The initial note is preserved under provenance/.
