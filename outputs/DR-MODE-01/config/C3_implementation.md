# C3 实现说明（C1/C2 结果产生前保存）

- C3(a,b) 均采用冻结主分析人群：≥20 岁、两天 Reliable、DRABF≠1；使用 WTDR2D 的周期内加权均值。A2 白皮书校准独立使用第一天人群与 WTDRD1，不混用分母。
- C3 仅对 C1 通过的主要结局，以及 C2 主参照（对照期均值）BH q<0.05 的次要结局运行。
- 首先在各结局原先定义的分析尺度（条数、log1p 摄入、能量百分比）计算 J→L 的变化。模式效应取 −DiD，解释比例 = (−DiD)/(L 第一天均值−J 第一天均值) ×100%；保留正负号，不取绝对值、不截断为 0–100%。分母为 0 时 NOT_RUN。
- 两种参照的解释比例均报告；合同的主 DiD 与 C2 主 FDR 使用对照期均值参照，不依据结果选择参照。
- C3(a) 严格保留合同的 L 均值 + (−DiD) 算术值。根据合同另一定义，−DiD 已是电话减现场的效应，该式不等于去除电话效应的现场反事实。报告必须将此值标作“合同原式算术结果”，不将其表述为已验证的模式校正均值；不默改为 +DiD。
- 对 log1p 结局，报告 E[log1p(X)] 尺度的变化。其指数变换不能冒充总体算术平均摄入。若另报告原始单位，必须明确采用每个人 log1p(X) 加同一常数的转换假设。
- C3(b) 为效应与观察变化的点估计比值；如供给区间，需包含分子分母协方差。不能把一个大的点估计比值解释为已证明的因果归因。
- C3(c) 仅在铁或钙达到 C2 的固定门槛时尝试 ncimultivar；若运行失败保留错误和 NOT_RUN，不换模型。若均未达门，记 NOT_RUN（不具备合同规定的资格）。
