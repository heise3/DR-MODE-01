# 敏感性实现（敏感性结果产生前保存）

- 敏感性不参与合同 GO 的新增门控，不据结果选择调整、周期或亚组。
- 间隔 3–10 天：在固定主分析完整协变量成人域中限制 interval∈[3,10]，重复全部固定结局与两种参照。
- 人口重新加权：每周期成人完整协变量且教育/种族有效者，以 WTDR2D 为起始权重，将年龄组、性别、RIDRETH3 种族/族裔和 DMDEDUC2 五级教育的四个边际分布 raking 到 J 周期同一分析域的加权边际。使用 survey::rake，四个边际均匹配；这是 raking，不能声称精确匹配四维交叉联合分布。记录每个边际误差、权重极值及 Kish 有效样本量。J 目标边际估计的不确定性不纳入条件 Taylor SE。最大迭代 100，容差 1e-7；不截尾、不结果驱动合并水平。若结构零或不收敛则 NOT_RUN。
- P：读取实际文件名 P_DR1TOT、P_DR2TOT、P_DEMO；使用 WTDR2DPP。替换 J，周期 G,H,I,P,L；P 时长 3.2 年、其他各 2 年，合并权重乘各时长/11.2；P 中点 2018.6。绝不同时纳入 J 与 P。
- 2–19 岁：保留两天 Reliable、DRABF≠1，年龄组改为合同次要人群相应的 2–5、6–11、12–19，其余固定协变量不变。报告 N 按人，不将儿童与成人池化。
- 所有敏感性报告完整面板；BH 在各分析、各参照的固定 10 个次要结局中分别计算，仅供描述，不取代 C2 主参照的 FDR。
