# S1-b implementation record (before model fitting)

- Inputs are the sealed v1.0 adult paired-reliable population and v1.0 DiD point estimates. Eligibility N=4,285 in L; the existing complete-covariate rule gives N=4,041 for the adjusted NCI model (244 missing interval). No new person exclusions, nutrient selection, trimming, winsorization, or GO/STOP gates.
- Software: official NCI `ncimultivar` 1.1.2. Joint daily-amount model for iron and calcium, person random effects, Box–Cox transformation selected with the package weighted day-1 procedure for each scenario. The package standard minimum-amount handling is recorded; no recall/person is silently dropped. Models use both recalls and WTDR2D (normalized internally by the package).
- Three scenarios: original; day 1 corrected using the control-mean DiD; day 1 corrected using the linear-extrapolation DiD. Correction is `expm1(log1p(intake) + DiD)`. Day 2 is byte-for-byte the original numeric vector in every scenario.
- Keep the exact v1.0 covariate model space: both weekend indicators, interval, both language indicators, both proxy indicators, age group, sex. Zero columns for unobserved language category 4 in L are omitted solely to obtain full rank; no categories are collapsed. Add a recall-order indicator as the NCI measurement-model nuisance parameter, not as a change to the frozen DiD regression. Interval is standardized numerically without changing its model space.
- Standard NCI distribution stage removes recall-order effect by setting Day2=0. Each person's two weekend indicators are integrated over 00/01/10/11 with weights 25/10/10/4, corresponding to the frozen Saturday/Sunday weekend definition. Other covariates retain their observed values. This is a first-recall-scale, model-based usual reported intake distribution, not biomarker-validated true intake.
- Four chains per scenario; each 12,000 iterations, 2,000 burn-in, thin 25; fixed seeds 102901–102904. Save traces, Gelman–Rubin and effective sample size diagnostics. These are numerical diagnostics, not additional scientific gates. Distribution simulation uses pooled chain posterior parameter means and 2,000 random-effect draws per person with common seed 20261029 across scenarios. Simulated rows are never reported as person N.
- Calcium EAR (mg/day): males 20–70 and females 20–50: 800; males >70 and females >50: 1,000. Adult pregnancy/lactation use the same calcium EAR. Iron EAR (mg/day): males 6; females 20–50 8.1; females >50 5; known pregnancy (RIDEXPRG=1) 22. Pregnancy status unknown and maternal lactation are not fully ascertainable from frozen files; no women are excluded or reclassified by invented status.
- Output is foods/beverages only, without dietary supplements, as specified by DRxTOT. Report calcium EAR-cutpoint inadequacy estimates conditional on the model. Iron output is explicitly a nominal below-EAR proportion, with `NO_VALID_RESULT` for interpretation as full-adult inadequacy prevalence: cutpoint assumptions fail for menstruating women, and life-stage ascertainment is incomplete. No probability-method substitution, nutrient substitution, or cutpoint optimization.
- Report paired scenario point differences in percentage points. Sampling/DiD uncertainty is not estimated by the MCMC diagnostic or simulation Monte Carlo error; no design-based prevalence CI will be fabricated. The original contract's Taylor rule is used for S1-c descriptive estimates. Absence of design-based uncertainty in S1-b will be recorded as a limitation/deviation.
- Budget: at most 24 hours from the first model attempt. If computation cannot complete, preserve logs and report NOT_RUN; do not change nutrients or thresholds.
